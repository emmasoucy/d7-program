# Section / Space

This is a standalone browser application for generating sectional spatial variations from overlapping rectangles.

## Open the application

Open `sectional_spatial_analysis_generator_enhanced.html` in any modern web browser. No installation, server, framework, or additional assets are required.

## Included capabilities

- Connected rectangular spatial variations with overlap-based grey fields
- Controls for scale, density, overlap, rotation, and outline overlap depth
- Local saving and restoration of variations
- Editable 5 × 5 parameter comparison matrix

Saved variations are stored in the browser's local storage for the browser in which the file is opened.
